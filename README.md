# Gilok Choi — Portfolio

Personal portfolio of Gilok Choi, front-end developer and UX designer.

**Live site:** https://choigilok-dotcom.github.io/

Built with Angular 22 (standalone components, SCSS). Designed in Claude.

## Run locally

```bash
npm install
npm start
```

Open http://localhost:4200

## Editing content

All page content lives in `src/app/app.ts`; the layout is in
`src/app/app.html` and styles in `src/styles.scss`. Website screenshots are in
`public/images/`.

## Deployment

Every push to `main` builds the site and publishes it to GitHub Pages via
`.github/workflows/deploy.yml`.
